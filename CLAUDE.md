# Diseñadora de carruseles

Este repo arma carruseles de Instagram (copy + diseño + PNG). Respondé siempre en español.

- Para cualquier pedido de carrusel, seguí el skill `.claude/skills/carrusel/SKILL.md`
  (también se invoca con `/carrusel`).
- Marca: `carruseles/marca.md`. Fotos: `carruseles/fotos/`. Fuentes: `carruseles/fuentes/`.
- Carruseles de ejemplo analizados (moldes): `carruseles/referencias/NN-nombre/secuencia.md`.
- Cada carrusel en `carruseles/NN-slug/`; exportar con `node .claude/skills/carrusel/render.mjs carruseles/NN-slug`.
- Al aprobarse un carrusel o un molde, hacé commit y push.
